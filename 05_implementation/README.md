# 05 実装ガイド

> このカテゴリは「設計（03）が終わった開発者・AIエージェントが、実際に手を動かすための手順」を置く場所です。
> 規約そのものは `rules.md` と `03_detailed-design/00_how-to-write.md` に、ここは**環境構築と実装の進め方**を書きます。

## このフォルダに置くドキュメント（想定）
以下はひな型の想定ラインナップです。プロジェクト開始時に必要なものから作成してください。

| ファイル（案） | 内容 |
|---------------|------|
| `00_dev-environment.md` | ローカル開発環境の構築手順（PHP/PostgreSQL、依存インストール、起動方法） |
| `01_project-structure.md` | ソースコードのディレクトリ構成とレイヤ対応 |
| `02_coding-guide.md` | 実装パターン・共通処理（バリデーション/例外/ロギング/認可の書き方） |
| `03_local-run-and-debug.md` | ローカル起動・デバッグ・テスト実行手順 |
| `04_git-workflow.md` | ブランチ・PR・コミットの具体手順（`rules.md` 第6章の実務版） |

## 作成の進め方
- まず `00_dev-environment.md` を用意し、「クローンしてこの手順を踏めば動く」状態を最優先で整える。
- 実装中に繰り返し説明している事項は、都度このカテゴリに追記して属人化を防ぐ。
- AIエージェントに実装させる際は、該当する実装ガイドのパスも指示に含める。

> このフォルダはまだ中身が未作成の予約カテゴリです。番号 05 は「実装ガイド」の定位置として確保しています。
